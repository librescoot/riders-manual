Bluetooth and apps

Use Bluetooth to connect a nearby phone to the scooter. During pairing, the display shows the PIN for up to 30 seconds or until the pairing request ends.

Apps

AppUse
stasis for unuFor Android and iOS. Transfers matching updates and sets hibernation with wake-up time.
Librescoot MobileSets up a compatible Android phone as an NFC key ({{p:handy}}).

Transferring an update

  1. Connect stasis for unu to the scooter. For a routine update on the same channel, pick a delta matching your installed version.
  2. Keep the phone close until the transfer finishes.
  3. Lock the scooter into standby so components can restart and activate the update ({{p:updates}}).

Bluetooth updates require Librescoot 1.2 or newer. A compatible app can transfer an update ahead of time and let you choose when to start installation. Use USB for maps, offline channel switches or recovery.

Clearing pairings

Before handing the scooter on, or if a device will no longer pair, open [[Menu > Settings > System]] in park mode and select "Clear Bluetooth Connections…". This erases all stored Bluetooth pairings; devices must be paired again afterwards.

USB in the footwell

Over USB you can copy maps, routing data or firmware and open the local web interface. This requires a computer and access to the main computer under the footwell cover.

Connecting a computer

  1. Power on and unlock the scooter, parked safely on its kickstand.
  2. For file transfers: first open [[Menu > Settings > System]], select "Update Mode…" and confirm. Skip this step for the web interface.
  3. Remove the footwell cover screws using a PH2 Phillips or H4 hex driver.
  4. Loosen the retaining screw, unplug the internal display USB cable from the MDB Mini-B port, and connect your computer there.

Once the display cable is unplugged, the menu is unreachable, so start Update Mode beforehand. The same port serves either Update Mode or the web interface ({{p:lsd}}).

Transferring files

  1. Open the mounted drive on your computer. Copy firmware into system-update/ and map or routing data into maps/.
  2. Safely eject the drive and unplug the USB cable to exit Update Mode. Reconnect the internal display cable so the scooter can also forward files to the display.
Before closing

Disconnect the computer. Reconnect and secure the internal display cable. Refit the footwell cover before riding.

The web interface

The web interface runs directly on the scooter. Manage settings, keys, navigation destinations, files and updates in a browser locally, with no app, SIM or cloud account.

Connecting over USB

  1. Power on and unlock the scooter. Connect your computer in the footwell as described on {{p:usb}}, without entering Update Mode.
  2. Open http://192.168.7.1:8090 in your browser.
  3. Open the section you need. Under "Settings", enable Advanced mode to search for a specific key.
  4. When finished, disconnect the computer, reconnect and secure the internal display cable, and refit the cover.

Anyone who reaches the interface can manage the scooter. Connect only trusted computers and change only settings whose effect you understand.

Installing updates

An update transfers and installs first. The new version becomes active once each component restarts.

After transferring

  1. Wait until transfer and installation complete.
  2. Lock the scooter into standby so pending update restarts can run. Exception: after a USB update, the main computer can restart while still in park mode.
  3. Unlock the scooter later and verify versions under [[Menu > Info > Components]] or via the version box by holding both brake levers for about three seconds in park mode.

During an automatic update

The status bar shows the update step: {{icon:download}} downloading, {{icon:preparing}} preparing, {{icon:installing}} installing or {{icon:reboot}} waiting for reboot. Download and install steps can show a percentage. When locking, the display shows active updates separately for DBC (display) and MDB (main computer) with status, target version and any error.

You can keep riding during a download or install; state changes may pause briefly. If an automatic update fails, the previous version remains active.

Release channel and schedule

Under [[Menu > Settings > System > Updates]], set Check Frequency, Change Update Type and Switch Release Channel. "Stable" is for everyday riding. "Testing" and "Nightly" carry test and development builds and may have bugs.

A Delta update downloads only changes from your installed version; a Full image uses more data. Switching channels can require a full download. Once 1.4.3 is installed, the scooter switches future firmware update checks automatically.

Mobile network and cloud

With internet access, the scooter can download updates and maps or use online map tiles and routing. Riding and offline navigation work independently of it.

Cellular internet

For compatible factory SIMs, the optional Sunshine service (sunshine.rescoot.org) offers paid connectivity plans. Alternatively, you can fit your own SIM with an adapter; that modification requires soldering and matching configuration.

The SIM screen separates SIM provider from the currently used network provider, and shows PIN2/PUK2 requests separately from a full SIM lock. Automatic system updates need internet, with no cloud account required.

Connecting a cloud account

A configured service such as Sunshine can provide scooter status, location and remote controls. The Cloud menu appears when the scooter has internet and the display is connected to the MDB.

  1. Open [[Menu > Settings > Cloud > Connect account]]. On the next screen, tap the right brake for "Start pairing".
  2. Scan the QR code or enter the short code manually before it expires.
  3. Approve pairing in your browser. The cluster shows progress and any connection errors.

Reading SMS

Messages sent to the scooter's SIM appear in park mode under [[Menu > Info > SMS]]. Optional forwarding is off by default and carrier charges may apply. See {{p:info}} for controls.
