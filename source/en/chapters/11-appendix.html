Menu overview

Open the main menu in park mode with two short pulls on the left brake lever. Some entries appear only when applicable.

Main menuWhat is inside
NavigationAddresses, saved locations, recent destinations and multi-stop routes.
Switch to Cluster View / Map ViewSwitch between available display views.
Lock ScooterLock the parked scooter into standby.
Toggle Hazard LightsTurn hazard lights on or off.
FaultsAlso appears directly here when faults are active.
SettingsAppearance, Vehicle, Map & Navigation, Keycards, System and Cloud.
Trip historyBrowse completed rides.
InfoComponents, Connectivity, Batteries, Consumption, Maps, Faults, Doctor and SMS.
Exit MenuReturn to the cluster or map screen.

See {{p:menue}} for operating the menu with the brake levers.

Appendix

Glossary

Park modeScooter powered on and unlocked, kickstand down.
Drive modeScooter ready to drive, kickstand up.
StandbyScooter locked, display off.
HibernationDeep sleep state with minimal power draw.
LockSwitch vehicle state into standby. The handlebar lock engages separately.
Handlebar lockLocks the steering at the left stop.
MDB / DBCMain computer in the footwell / display computer on the handlebar.
AUX / CBBInternal backup batteries inside the scooter.
Unlock cardEnrolled NFC card used to unlock and lock the scooter.
Teach-in cardControls teach-in mode for other keys; never unlocks the scooter.
Delta updateUpdate containing only changes from a matching installed version.
Update ModeUSB mode mounting the scooter as a drive for file transfers.
SunshineOptional cellular and cloud service (sunshine.rescoot.org).
Web interfaceBrowser-based local management running on the scooter.
